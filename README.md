# Njuškalo Real Estate Analysis (Dubrovnik)

This project analyzes apartment prices in Dubrovnik using data from Njuškalo. The main focus is on price per square meter and differences between districts.

## Project goals

- Clean and prepare real estate data
- Calculate price per square meter
- Analyze cheapest and most expensive listings
- Compare prices between districts in Dubrovnik
- Visualize data using graphs

## Project structure


data/ Excel dataset
analysis.py Main Python script
requirements.txt Dependencies


## Requirements

Install dependencies with:


pip install -r requirements.txt


## How to run

Run the analysis script:


python main.py


## Libraries used

- Python
- Pandas
- Matplotlib

## Main insights

- Price per square meter varies significantly between districts
- Some districts (e.g. Old Town) are much more expensive
- Smaller apartments often have higher price per m²
